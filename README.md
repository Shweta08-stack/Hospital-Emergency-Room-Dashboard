# 🏥 Hospital Emergency Room Dashboard

✨ *An interactive Excel dashboard to analyze hospital emergency room performance and patient insights.*

---

## 📊 Project Overview

This project focuses on analyzing hospital emergency room data using Excel.
The dashboard provides key insights into patient flow, waiting time, satisfaction levels, and admission trends.

---

## 🎯 Objectives

✔ Monitor total patient visits
✔ Analyze average wait time
✔ Evaluate patient satisfaction score
✔ Track admission vs non-admission rates
✔ Understand patient distribution by age group and department

---
